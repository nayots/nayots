# Surface brief — GitHub profile README

Scope: README.md and every image it shows (assets/*.svg). Visitor mode: Experience — the profile is itself the work; the artifact leads from the first viewport, the interface recedes.

Audience: recruiters, engineers and developers arriving from a repo, CV or LinkedIn. Job: decide in seconds who this is and click through to real work. Proof: the live contribution sky, the real AI Usage Monitor widget, the live nayots.com. Constraints: GitHub <img> rendering (no script, no external loads), light + dark GitHub themes, 360-830px wide, public repos only, locked nayots palette and marks.

## Direction contract

THESIS: The profile is one night sky. Every image is a plate cut from the same navy sky, so scrolling reads as one continuous observation, not a stack of widgets. Refuses the category default: centered "Hi there" heading, badge wall, three third-party stats cards.

OWN-WORLD: Flat navy #04060D plates, 840-unit viewBox, 20-unit radius, nebula cores (#141C3A) only away from the marks. Three star classes on every plate: dust (ice-white dots), stars (star-tone), glints (gold four-point stars echoing the keystone). Space Grotesk: 700 lowercase -0.035em for headings in ice-white; 500 for body in ice-white at reduced opacity; gold-highlight only for actions and glints. Hairline constellation lines in ice-accent at low opacity.

STORY: Visitor sees the name as stardust, learns breadth (.NET, AWS, front end, infrastructure, AI) as constellations, sees two real pieces of work, then the live year of activity as a sky; leaves via nayots.com or LinkedIn.

FIRST VIEWPORT: Hero plate full column width, 840x340: official animated particle wordmark framed on its own clear space so its ink spans ~60% of the plate; "stoyan grigorov" 700 36px close beneath (48px in the narrow layout); "software engineer · sofia, bulgaria" 500 19px under it; starfield ignites left-to-right and twinkles; nebula cores lower-left and upper-right. Below, one line of Markdown intro. Then one continuous run of plates (constellations, two work plates, sky) sharing seams. Every plate swaps to a narrow layout under 540 css px.

FORM: Established world (nayots brand); composition pinned by the owner, position 1 of 1; no concept roll ran (precisely specified request). Seed key: none. Owner approval, verbatim, 2026-10-01, replying to the in-chat design that listed this exact composition: "approved, go ahead with the font download". Signature interaction: constellation lines draw themselves in; the sky plate is regenerated daily from the real calendar.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
